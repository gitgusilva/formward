# Installation

Install from [npm](https://www.npmjs.com/package/formward):

```bash
npm install formward
```

Optional, for schema support (Zod / Yup):

```bash
npm install zod    # and/or  yup
```

- **Package:** [formward on npm](https://www.npmjs.com/package/formward)
- **Repository:** [gitgusilva/formward](https://github.com/gitgusilva/formward)
